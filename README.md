# My Health Record V8.2 — GitHub Pages PWA Fix

แพ็กเกจนี้แก้การกำหนดเส้นทาง PWA ให้ใช้ URL แบบ relative เพื่อรองรับ GitHub Pages ที่เผยแพร่ใน repository path เช่น `/My-health-/`.

## อัปเดตไฟล์
1. แตก ZIP นี้
2. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดใน ZIP ไปทับไฟล์เดิมใน repository `My-health-` (วาง `index.html` ไว้ที่ root)
3. รอ GitHub Pages deploy เสร็จ
4. เปิด `https://hack1986.github.io/My-health-/` ด้วย Chrome ขณะออนไลน์ รอหน้าเว็บโหลดจนเสร็จ แล้วเปิดอีกครั้งหนึ่ง

## สำคัญ: แก้แอปที่เคยติดตั้งแล้ว
ถ้า Android แสดงว่าแอปติดตั้งแล้วแต่เปิดไม่ได้:
1. ถอนเฉพาะไอคอน/แอป My Health Record รุ่นที่เปิดไม่ได้ออกจากหน้าจอหรือรายการแอป (อย่ากดล้างข้อมูลเว็บไซต์/ล้างพื้นที่เก็บข้อมูล Chrome)
2. เปิด URL ด้านบนใน Chrome ขณะออนไลน์
3. แตะเมนู ⋮ → ติดตั้งแอป (หรือ เพิ่มลงในหน้าจอหลัก แล้วเลือกติดตั้ง หาก Chrome แสดงตัวเลือก)
4. เปิดจากไอคอนใหม่

การถอน PWA ออกจากหน้าจอโดยไม่ล้างข้อมูลเว็บไซต์ โดยทั่วไปไม่จำเป็นต้องลบข้อมูลเว็บไซต์เดิม แต่ควรสำรองข้อมูลสุขภาพก่อนดำเนินการเสมอ

## ตรวจสอบหลังติดตั้ง
- เปิดแอปจากไอคอนขณะออนไลน์อย่างน้อยหนึ่งครั้ง
- รอให้หน้าแรกโหลดเสร็จ
- เปิดโหมดเครื่องบินแล้วลองเปิดแอปจากไอคอนอีกครั้ง
- ถ้าข้อมูลเดิมไม่แสดง ให้หยุดและอย่าบันทึกข้อมูลใหม่ทับ จนกว่าจะตรวจสอบแหล่งจัดเก็บเดิม

## ความเป็นส่วนตัวและข้อจำกัด
- GitHub Pages ใช้เผยแพร่ไฟล์แอปเท่านั้น; โค้ดแอปไม่มีระบบบัญชีหรือ Cloud Sync สำหรับข้อมูลสุขภาพ
- ข้อมูลสุขภาพเก็บในพื้นที่จัดเก็บของเบราว์เซอร์บนอุปกรณ์นั้น
- การติดตั้งครั้งแรกและการรับไฟล์อัปเดตต้องใช้อินเทอร์เน็ต
- การเตือนยาในเว็บไม่รับประกันเมื่อปิดแอปหรือระบบพักเบื้องหลัง
- สำรองข้อมูลจากเมนูในแอปเป็นระยะ และอย่าล้าง Site data

## ไฟล์หลัก
- `index.html` — แอป
- `manifest.webmanifest` — การติดตั้ง PWA
- `service-worker.js` — แคชสำหรับออฟไลน์
- `icons/` — ไอคอนแอป
- `.nojekyll` — ป้องกัน GitHub Pages ข้ามไฟล์/โฟลเดอร์ที่ขึ้นต้นด้วยขีดล่าง
